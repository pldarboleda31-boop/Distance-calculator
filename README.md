# Distance-calculator
# Description
This is a distance calculator, it calculates distance based on what the given is.
## How to run 
1. Download this repository
2. Open distance_calculator.py
3. Run the program
4. Enter the coordinates asked
5. The program will display the distance
## Input needed:
- x1 is the first coordinate of point one
- y1 is the second coordinate of point one
- x2 is the first coordinate of point two
- y2 is the second coordinate of point two
